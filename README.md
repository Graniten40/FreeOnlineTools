# FreeOnlineTools

FreeOnlineTools is a simple landing page for a growing collection of free browser-based tools.

The goal of this project is to collect useful online tools in one place, such as barcode generators, QR code generators, invoice tools, VAT calculators, and other practical web utilities.

## Live Tools

- Free Barcode Generator
- Free QR Code Generator

## Coming Soon

- Free Invoice Generator
- VAT Calculator

## Features

- Responsive landing page
- Tool cards with live and coming soon states
- External links to live tools
- SEO-friendly title and content structure
- Mobile-friendly layout
- Built with React, Vite, and TypeScript.

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Cloudflare Pages

## Project Purpose

This project was created as a central hub for free online tools. Each tool is designed to be simple, fast, and easy to use directly in the browser without requiring an account.

The project also works as a portfolio project to demonstrate frontend development, responsive design, SEO structure, and deployment with Cloudflare Pages.
